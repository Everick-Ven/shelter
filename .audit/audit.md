### А2 (P1) prefers-reduced-motion — ПОДТВЕРЖДЕНО

### А3 (P2) Фокус — ПОДТВЕРЖДЕНО, с уточнением

Правило ~249 гасит outline для `.ni,.tab,.swatch,.tcard,.ach-card,
.profile-award-slot,.seg button`; собственный индикатор есть только у
`.ach-card` (~1654) и wp-семейства (~3800–3988) — остальные 6 селекторов
остались **без индикатора**.

### А3а (баг владельца) Белая рамка `#heroInput` — НЕ ВОСПРОИЗВЕЛОСЬ на текущем коде
Замер (`.audit/before/shots/hero-focus-computed.json`): в состоянии
`:focus`+`:focus-visible` у `#heroInput` — `outline:none`, `box-shadow:none`,
`border:0` при трёх путях фокуса (программный, клик, Tab-обход). Пиксельный
дифф hero/hero-focus по краю карточки идентичен (пик пирамида гало 209/207 —
одинаков). Яркое гало вокруг карточки, которое видно на скриншотах, — это
**штатное свечение карточки** (`#heroFx` canvas + `--bar-line` ring): оно
присутствует и без фокуса, и с выключенным `.omni-ring`, тенями и декором —
то есть не рамка поля. Вероятно, скриншот владельца снят со сборки, где
действовало иное правило (в ТЗ: набор быстрых ссылок на «баге» совпадает с
текущим, на «эталоне» — другой). Правку всё равно делаем защитной (ТЗ §2.9).
Приложение: скриншоты `graphite-hero*.png`, `edge-crop.png` (в отчёте).

## Ревью движения (emil-design-eng)

| Before | After | Why |
|---|---|---|
| `animation:tabIn .42s` на появлении вкладки | `.28s` | появление вкладки — частое действие; <300ms по правилу длительности |
| `animation:toastIn .5s` | `.28s` + симметричный `toastOut .18s` | тост — быстрое уведомление; вход <300ms, выход быстрее входа |
| `animation:modalIn .42s` / `menuIn` (см. код) | `modalIn .3s`, `menuIn .2s` | модалка/меню — UI <300ms; асимметрия выхода |
| `@keyframes` для тоста/типа (прерываемость) | оставлено | в замедлении не подтверждено мешательство быстрых повторов; переход на transition — отложено с причиной |
| `prefers-reduced-motion`: 4 узких блока | +1 общий блок | keyframes сохраняют имена/fade, transform/scale удалены; ambient на паузе, переходы только по opacity/цвету (критерий 3) |
| `ease-in`/`transition: all` | 0/0 — не трогаем | уже соответствуют правилам |
| бесконечные: `dlSweep`,`shimmer`,`.rec i`,`dlRunBlink`,`.ni.hot` glow | не трогаем | привязаны к живому состоянию (загрузка/запись/скачивание) — ложные срабатывания детектора |

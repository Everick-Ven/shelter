# SHELTER

Extensible desktop browser based on Chromium Embedded Framework for Windows x64 and macOS Intel x86_64.

The project is currently at Phase 1: foundation. CEF is downloaded by `scripts/bootstrap-cef.sh` and is excluded from Git. Build directories must remain outside the repository.

See `docs/ARCHITECTURE.md`, `docs/CEF.md`, `docs/BUILD_WINDOWS.md`, `docs/BUILD_MACOS.md`, `docs/DEVELOPMENT.md` and `docs/RELEASE.md`.

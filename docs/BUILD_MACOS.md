# macOS Intel

Use Xcode Command Line Tools, CMake 3.24+ and Ninja. CEF subprocess sandboxing is disabled because SHELTER currently sets `no_sandbox=true` and ships without sandbox entitlements. Run: `export CEF_PLATFORM=macos; ./scripts/bootstrap-cef.sh; cmake -S . -B ../shelter-build-macos -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_OSX_ARCHITECTURES=x86_64 -DUSE_SANDBOX=OFF; cmake --build ../shelter-build-macos; ctest --test-dir ../shelter-build-macos --output-on-failure`. The CMake project also forces `USE_SANDBOX=OFF` for macOS builds. CI packages the app with an ad-hoc code signature and verifies the nested CEF helper; public distribution still requires Developer ID signing and notarization to avoid Gatekeeper warnings.

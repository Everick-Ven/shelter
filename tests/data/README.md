# Фикстуры CRX3

Пакеты `.crx` в каталоге создаются детерминированно скриптом
`tools/gen_crx3_fixtures.py`; проверка совпадения выполняется параметром
`--check`. Фикстуры RSA и ECDSA подписаны отдельными тестовыми закрытыми
ключами, встроенными в скрипт. Эти ключи и пакеты предназначены только для
регрессионных тестов и не должны использоваться в SHELTER или выпускных
расширениях.

Набор включает корректные RSA-2048 и ECDSA P-256 пакеты, пакет с чужим proof,
а также повреждённые архив, signed header, CRX ID и подпись, рассчитанную без
нулевого байта контекста. `crxviewer_1.6.10_public_key.der` — публичный ключ из
опубликованного разбора CRX3-пакета CRX Viewer 1.6.10; его ID
`jifpbeccnghkjeaalbbjmodiffmgedin` используется только для проверки алгоритма
вычисления ID, не для проверки старой подписи:
https://github.com/Rob--W/crxviewer/issues/83
